# DC-Motor-Servo-Ultrasonic
DC Motors, Servo & Ultrasonic Simulation
Project Description
This project simulates a robotic system using Arduino, L293D Motor Driver, 4 DC Motors, Servo Motor, and an Ultrasonic Sensor in Tinkercad.
Task 1
The robot controls four DC motors with the following sequence:
Move forward for 30 seconds.
Move backward for 60 seconds.
Turn right and left alternately for 60 seconds.
Task 2
A Servo Motor and Ultrasonic Sensor are added to detect obstacles.
The ultrasonic sensor continuously measures the distance.
If an obstacle is detected at 10 cm or less:  
The DC motors stop immediately.
The servo motor rotates to change direction (or scan the surroundings) to avoid the obstacle.
Components
Arduino Uno
L293D Motor Driver
4 DC Motors
Servo Motor
HC-SR04 Ultrasonic Sensor
Breadboard and Jumper Wires
Simulation
The circuit was designed and tested using Tinkercad.
